Public Funding Database

Data is only as useful as it is accessible.

Accessible data builds capacity, enabling community insight to drive local decision making.

Overview

The Hawai’i Funding Project brings together public funding data into one place: collecting from federal and state sources, standardizing so that categories, formats, and terminology match across systems, and making it available for download so stakeholders can:

  • Access state and federal funding data in one place
  • Conduct analyses and generate insights
  • Connect public funding data to local priorities and planning

We update our sources and download offerings regularly, ensuring a reliable, accurate, and up-to-date view of Hawai’i’s public resources.
