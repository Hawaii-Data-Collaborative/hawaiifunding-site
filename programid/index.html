State Program Profiles

What is behind the programs that shape Hawaiʻi?

Seeing the full picture of any program enables more informed advocacy and decision-making.

Overview

State programs are the backbone of public investment in Hawaiʻi, but understanding any single program means piecing together data from budget bills, legislative testimony, executive reports, and more. This tool consolidates that information so stakeholders can:

  • Track a program's appropriation history across fiscal years
  • See who has received grants and contracts tied to a program
  • Access related documents and program narratives in one place

All underlying data is available for download, and you can learn more about our sources and methodology.
